# Brand context index

The single source of truth for every agent. Fill these files in before using the team; agents flag anything missing instead of inventing it.

| File | Read it for |
|---|---|
| `company.md` | What the company and products are, partners, what we are not |
| `glossary.md` | Canonical terms and deprecated forms (enforced by copy-editor and brand-voice-guardian) |
| `voice-and-tone.md` | Voice, tone per channel, style rules, words to avoid |
| `positioning.md` | Positioning statement, messaging pillars, taglines, value props |
| `competitors.md` | Competitor comparison and rules |
| `audiences.md` | ICP and personas |
| `claims-and-proof.md` | Approved numbers and required caveats |
| `source-authority.md` | Which source wins in a conflict |
| `channels.md` | Channels used / not used, communities, tracked pages |
| `sources/` | Raw provenance (append-only), filed by `/brand-refresh` |

Every file carries `last_reviewed` frontmatter; `/brand-audit` flags files older than 60 days.
